# SwiftPage Native Lab

Minimal native SwiftUI reference for comparing `NavigationStack` interactive
pop behavior with `SwiftPage`.

Open `SwiftPageNativeLab.xcodeproj`, run the `SwiftPageNativeLab` scheme, tap
**Go to red**, and record back gestures from the screen edge and center. The
detail screen also contains a horizontal `ScrollView`, a `Slider`, and a custom
drag progress control for gesture-conflict checks.
